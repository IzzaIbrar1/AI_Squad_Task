# AI Utilization Report
## Weekend Project: Loan Default Prediction Pipeline

### LLM Used
Claude (Anthropic); Sonnet 4.6

### How AI Was Used

**1. Dataset Sourcing**
No dataset was provided for this task. Claude helped me find a suitable loan default dataset online that matched the project requirements.

**2. Error Handling**
I wrote all the code for this pipeline, data cleaning, encoding, train-test split, SMOTE, scaling, training three classifiers, and generating ROC-AUC comparisons. When I ran into errors while executing my code, Claude helped me debug and fix them.

**3. Review**
Claude reviewed the explanations and conclusions I wrote in the notebook's markdown cells and gave feedback on them.

### Reflection
Claude was used as a support tool for dataset sourcing, debugging, and reviewing my written explanations. The pipeline design, implementation, and analysis were done by me.
